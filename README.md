# Uthman Abubakar — Remote Work Portfolio

Professional portfolio for remote administrative support, data operations, research, content, and AI evaluation.

**Live site (after enabling GitHub Pages):** https://uthman-mote.github.io/remote-work-portfolio/

## Enable GitHub Pages

1. Open **Settings → Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)` · Save
4. Wait 1–2 minutes, then open the link above
